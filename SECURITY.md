# Security policy

Neural Lab is an educational local application and does not require API keys or credentials.

## Reporting a concern

Please use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository owner privately before publishing details that could put users at risk.

## Safe use

- Do not commit tokens, credentials, private datasets, or personal images.
- Treat downloaded model checkpoints as untrusted input. Prefer files you created yourself.
- Keep dependencies updated and review automated security alerts.
- The application processes uploaded images locally in the running Streamlit process; do not upload images you do not have permission to use.
